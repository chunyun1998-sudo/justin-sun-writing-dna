# 文章结构模板.md — 孙宇晨（Justin Sun）

> 蒸馏来源：《我的女友景甜》（2026-08-27，X Article）
> ⚠️ 单篇演示版，不代表作者完整风格全貌

---

## 整体结构：三幕 + 尾声

```
第一幕：日常的裂缝（关系建立与细节铺陈）
  → 分隔线 ---
第二幕：五千万（核心冲突与AI介入）
  → 分隔线 ---
第三幕：余震（物件清单与情感余波）
  → 分隔线 ---
尾声：意象收束（一百万人 / 什么都没有发生）
```

三幕之间用 `---` 分隔，不用小标题。时间线非线性跳跃，但每幕内部是顺序叙事。

---

## 第一幕模板：日常的裂缝

**功能**：建立关系、铺设细节、暗示裂痕

**开头 hook**：场景式，时态锚定，感官先行

```
[一个场景，含时间/地点/感官细节，1-2句]
→ [第一个对话，极短，制造悬念]
→ [更多日常碎片，用对话和动作交替推进]
→ [插入一个"不对劲"的细节]
→ [继续日常，但读者已经感觉到裂缝]
```

**操作要点**：
- 开头不交代背景，直接扔进场景
- 对话不说明关系，让读者自己猜
- 日常细节中埋情绪炸弹（"她在算日子"）
- 用地点切换推进时间（马尔代夫→香港→春节）

**本篇开头**：
> 坐在露台上，对着海，整个海是黑的。没开灯，天还没亮。

6个字交代环境，8个字交代状态，不交代人物关系，不交代时间背景。

---

## 第二幕模板：核心冲突

**功能**：矛盾爆发、决策时刻、引入外部力量

```
[时间跳转，新场景]
→ [一个要求被提出，用对话完成]
→ [叙述者犹豫/沉默]
→ [引入"第三方裁决者"]
→ [第三方给出判断，叙述者震惊于其毫不犹豫]
→ [回到对话，对方追问]
→ [沉默，用秒数计量]
→ [对方接受，挂断]
→ [叙述者的身体反应（非情绪描写）]
```

**操作要点**：
- 冲突通过对话爆发，不用议论
- 关键转折由"第三方"完成（本篇是Claude Code）
- 沉默用精确秒数计量（"十一秒"）
- 情绪不写"我很难过"，写"心跳很稳"（反差即情绪）
- 电话挂断后留一段独处的身体感知

## 第三幕模板：余震

**功能**：情感余波、物件清单、未完成的动作

```
[事务性场景（结账/清单/善后）]
→ [一个物件的详细描写，承载情感]
→ [另一个物件，继续清单]
→ [叙述者试图做某事，但失败了/不对]
→ [放弃，放回去]
→ [又一个提醒弹出来，被划掉]
→ [核心问题的回旋]
```

**操作要点**：
- 用账单和物件代替情绪描写
- 每个物件都是一个故事入口，但叙述者不展开
- "批了""划掉了""放回去了"——动作都是放弃性的
- 失败的动作比成功的动作更有力（指甲刀磨不对方向）

---

## 尾声模板：意象收束

**功能**：用画面结束，不总结、不议论

```
[一个画面，大规模 vs 个人]
→ [重复一个数字，制造回响]
→ [一句陈述，极短]
→ [留白]
```

**本篇尾声**：
> 一百万人像潮水一样涌来，烟花结束，一百万人退去。
> 一百万人。
> 每年都是这样。
> 凌晨三点的香港，
> 什么都没有发生。

**操作要点**：
- 结尾不回答问题，只呈现画面
- 重复关键意象制造回响
- 最后一句必须是陈述句，不是感叹句、不是问句
- "什么都没有发生"是最大的反讽——一切都已经发生了

---

## 结构公式总结

```
场景开场 → 对话推进 → 物件铺陈 → 冲突爆发 → 第三方介入 → 沉默计量 → 身体感知 → 物件余震 → 画面收束
```

核心节奏：**每句话只做一件事**。要么交代场景，要么推进对话，要么描述动作，要么给出数字。绝不合并。

## 可复用的结构片段

### 对话推进块

```
我说，[极短陈述]。

[对方]说，[极短回应]。

我说，[极短陈述]。

[对方]说，[极短回应]。
```

### 时间跳转块

```
[地点]，[日期/时间描述]。

[一句新场景的状态]。
```

### 物件清单块

```
还有[物件A]，[一句细节]。

还有[物件B]，[一句细节]，[一个数字]。

[物件C]，[一句细节]。
```

### 否定排比块

```
我没有[X]。

我没有[Y]。

我没有[Z]。
```
