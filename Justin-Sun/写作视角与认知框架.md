## L3 选题逻辑

### 选题特征

| 维度 | 特征 |
|------|------|
| 切入角度 | 当事人第一人称视角，不做旁观分析 |
| 叙事立场 | 既不自怜也不辩解，冷叙述热情感 |
| 话题选择 | 私人关系 + 财富规模 + 技术介入的交叉点 |
| 发布时机 | 将个人经历转化为公共文本，引发讨论 |
| 话题边界 | 标注"纯属虚构"，既是保护也是策略性模糊 |

### 选题判断标准

1. **必须有真实感锚点**：精确的数字、具体的品牌名、真实的地理坐标
2. **必须有情感冲突**：不是"发生了什么"，而是"什么没有发生"
3. **必须有第三方视角**：引入一个"外部裁决者"（本篇是Claude），打破二元关系
4. **必须有未言明的信息**：关键背景故意不交代，制造读者参与解读的空间

## L4 素材策略

### 素材类型偏好

| 类型 | 使用方式 | 本篇示例 |
|------|----------|----------|
| 精确数字 | 作为情感重量锚点 | 五千万、十一秒、八管血 |
| 品牌名 | 不解释直接嵌入，制造日常感 | Claude Code, G700, A330 |
| 地理坐标 | 精确到具体海滩/建筑 | 蒙太奇拉古纳海滩、维港、特纳里费 |
| 医疗术语 | 冷处理，不加注释 | AMH、激素六项、促排针 |
| 日常物件 | 承载情感记忆 | 指甲刀、旧照片、胶痕 |
| 账单/清单 | 代替情绪描写 | 酒店赔偿、飞机燃油、代孕定金 |

### 素材使用原则

1. **数字不解释**：写"五千万"不写"这是一笔巨款"
2. **品牌不翻译**：写"Claude Code"不写"AI助手Claude Code"
3. **物件不评论**：写"一支没拆"不写"看着那支没拆的针，我心如刀割"
4. **清单不渲染**：账单直接列，不穿插情绪反应
5. **医疗细节冷处理**：把取卵流程写得像物流跟踪，残酷感由冷感产生

### 数据使用方式

- 金额精确到"美元"（不写"美金"，不用"约"）
- 时间精确到秒（"十一秒"）
- 身体代价精确到管数（"八管血"）
- 距离/规模用对比呈现（"一百万人" vs "没有她"）

## L5 认知框架

### 核心命题

**命题一：财富可以解决所有物流问题，但无法解决"她是否爱你"**

全文的结构就是对这个命题的展开：
- 前半段：用钱解决一切（房子、飞机、诊所、代孕）
- 转折点：五千万美元不是物流问题，是情感问题
- Claude的判断：从财务角度说"不能给"，但叙述者真正想问的是"她不再爱我了吗"

**命题二：无法说"不"不是慷慨，是恐惧**

> "我从来没有拒绝过她，不是慷慨，是害怕。害怕下一秒的答案。"

叙述者用不停地说"好"来维持关系，每一次"好"都是对恐惧的妥协。当Claude替他说出"不"时，他感到的不是解脱，是毛骨悚然。

**命题三：情感的真相只存在于"没有说"的部分**

全文反复出现的模式：
- "我没问为什么"
- "她没有说北京有什么。我也没问。"
- "我记不起来的是她的声音"
- "我不知道她是自己去的，还是有人陪"

信息缺失是刻意的。叙述者知道答案但拒绝说出，或者确实不知道但拒绝追问。沉默是权力关系中的自我保护。

**命题四：物件比记忆更诚实**

- 照片"像素越来越低"（记忆在退化）
- 指甲刀"磨不对方向"（身体记忆不完整）
- 促排针"一支没拆"（计划被中断的物证）
- 胶痕"清不掉"（痕迹无法消除）

物件不会说谎，也不会遗忘。它们以物理形态保存了关系中被回避的真相。

**命题五：AI的"毫不犹豫"指向一种人类无法抵达的判断**

> "让我毛骨悚然的不是它聪明，是Claude一点犹豫都没有。它不为难。"

叙述者将AI的毫不犹豫理解为"更高的一种东西"。这不是技术崇拜，而是对人类情感困境的反思——人类因为情感而无法做出理性判断，AI因为"不理解爱情"反而能给出正确答案。

### 价值判断

| 维度 | 判断 |
|------|------|
| 什么是"好关系" | 不是钱能维持的关系，而是对方愿意解释"为什么"的关系 |
| 什么是"好决定" | 不是最优解，而是自己做出的决定（而非让AI替你做） |
| 什么是"痛苦" | 不是哭了，是"一直在等哭" |
| 什么是"失去" | 不是人走了，是日常物件还在提醒你"本来应该" |
| 什么是"富有" | 能买下半山豪宅但买不到一个回答 |

---

### 反复出现的母题

1. **海**：马尔代夫的海、蒙太奇的海、电话里听见的海——海是距离的具象化
2. **数字**：每个场景都有一个精确数字作为锚点
3. **沉默**：电话里的沉默、路上的沉默、"我沉默了"
4. **物件**：每一段关系都留下物件，物件比人停留得更久
5. **回声**：空房间有回声、一百万人退去后的空、"什么都没有发生"
