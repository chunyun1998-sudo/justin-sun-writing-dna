| 维度 | 特征 |

**核心特征**：视觉极简到不存在。文字本身就是视觉——短句、一句一段、大量留白构成的"竖排节奏感"。

## 二、排版规律

### 段落节奏

```
[一句话]

[一句话]

[一句话]

[一句话]
```

这是默认节奏。四句话占四行，视觉上是一个竖列。

偶尔出现密集段落：

```
[一段3-5句话的密集段落，通常是信息清单或背景交代]

[回到一句一段]
```

**规律**：密集段落只用于"事务性信息"（医疗清单、账单明细、看房过程），回到情感叙述立即恢复一句一段。

### 分隔线使用

全文用 `---` 分隔三幕，共2条分隔线。不用小标题、不用空行组、不用序号。分隔线是唯一的结构标记。

### 引用格式

对话不加引号的方式有两种交替使用：
1. **对话词 + 逗号 + 内容**：`我说，[内容]。` / `她说，[内容]。`
2. **引号包裹**：仅用于极少数关键对话

大部分对话用第一种方式，视觉上更干净。

## 三、留白即节奏

全文2600字，109段。平均每段24字。如果把这篇文章打印在A4纸上：

- 竖向看：大量空白，文字只占页面1/3
- 横向看：每行很短，右边大片空白
- 视觉效果：像一个人在自言自语，每句话之间都有停顿

**留白的功能**：
1. 逼迫读者慢下来
2. 每句话的重量被放大
3. 对话之间的沉默被视觉化
4. 碎片感本身成为叙事语言

---

## 四、数字的视觉处理

数字在文中不做任何视觉强调（不加粗、不放大、不变色），但通过精确度和重复制造视觉锚点：

- "五千万"出现多次，每次都在新段落开头
- "一百万人"在尾声连续出现三次，形成视觉锤
- "十一秒"独占一个语境，前后都是沉默

## 五、可复用的视觉规则

| 规则 | 操作 |
|------|------|
| 一句一段 | 默认格式，例外仅在信息密集时 |
| 分隔线分段 | 用 `---` 分隔大段落，不用小标题 |
| 零装饰 | 不加粗、不引用框、不列表（除特殊场景） |
| 数字自然嵌入 | 不做视觉强调，让精确度本身产生冲击 |
| 对话格式 | `X说，内容。` 统一句式 |
| 留白控制 | 段落之间空一行，句子之间不空行 |
| 尾声重复 | 结尾意象重复2-3次，每次独占一段 |
