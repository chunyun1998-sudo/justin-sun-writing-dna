## 一、句式特征

| 指标 | 数值 | 解读 |
|------|------|------|
| 平均句长 | 14.0 字 | 极短，接近口语节奏 |
| 短句(≤15字)占比 | 62.9% | 超过六成句子是短句 |
| 长句(≥50字)占比 | 0% | 全篇没有一句长句 |
| 总句数 | 175 句 | 高密度碎片化叙述 |

**核心规律**：绝不写长句。每句话只承载一个信息单元，多余的信息拆成下一句。

## 二、段落特征

| 指标 | 数值 | 解读 |
|------|------|------|
| 总段落数 | 109 段 | 2600字/109段，极度碎片化 |
| 平均段落字数 | 24.0 字 | 每段不到两句 |
| 一句一段占比 | 68.8% | 近七成段落只有一句话 |
| ≤20字段落占比 | 67.9% | 视觉上呈"竖条状"排列 |
| 最短段落 | 4 字 | "心跳很稳。" |

**核心规律**：一句一段是默认格式。只有在信息密集不可拆分时（如医疗检查清单、账单明细）才合并为多句段落。

## 三、标点与格式

| 标点 | 出现次数 | 使用方式 |
|------|----------|----------|
| 句号(。) | 171 | 绝对主导，每句必结 |
| 引号("") | 6对 | 仅包裹对话内容 |
| 破折号(——) | 1 | 几乎不用 |
| 冒号(：) | 2 | 极少，仅在"她说："句式中 |
| 省略号(……) | 0 | 完全不用 |
| 分隔线(---) | 2 | 三幕结构分隔 |

**核心规律**：标点极简到接近消失。句号是唯一的节奏控制器。不用破折号、不用省略号、不用感叹号。引号只用于对话。

## 四、高频词与表达模式

### 对话驱动型表达

| 表达 | 出现次数 | 功能 |
|------|----------|------|
| 她说 | 16 | 对话引入，主语+动词 |
| 我说 | 15 | 对话引入，主语+动词 |
| 妈妈说 / 妈说 | 7+7=14 | 第三方对话引入 |
| 助理 | 7 | 事务性角色 |
| 我想 | 7 | 内心独白标记 |
| 不知道 | 5 | 信息缺失标记 |

**核心规律**：对话是叙事发动机。"她说/我说/妈妈说"三种句式交替推进剧情，几乎不用其他过渡词。

### 数字作为情感锚点

全文出现的精确数字：

| 数字 | 语境 | 功能 |
|------|------|------|
| 五千万 | 美元，要的钱 | 核心冲突的量化 |
| 一百万 | 每张卡日限额 | 财富细节的真实感 |
| 八管血 | 抽血检查 | 身体代价的具象化 |
| 十一秒 | 电话沉默 | 情感重量的计量 |
| 十四天 | 马尔代夫 | 时间跨度 |
| 一百万人 | 维港烟花 | 对比孤独 |
| 2007年 | 旧照片 | 时间距离 |
| 三十四岁 | 代孕者 | 事实陈述 |
| 二十万美元 | 代孕定金 | 不可退的成本 |
| 四十几页 | 某份文件 | 未言明的信息 |

**核心规律**：每个数字都承担情绪功能，不是数据罗列。精确到"十一秒"和"八管血"制造真实感和痛感。

### 重复结构

| 重复模式 | 示例 |
|----------|------|
| "我说X / 她说Y" 交替 | 大量对话段落 |
| "妈妈说" 连续出现 | 妈妈提出一个又一个要求 |
| "我没有X" 否定排比 | "我没有哭""我没有说话""我没有在想任何事" |
| "后来我X" 时间跳转 | "后来我才知道""后来我把""后来我才知道" |

## 五、人称与视角

- 第一人称"我"贯穿全篇，视角锁死在叙述者
- "她"指代景甜，从不直呼其名（除一处"景甜说"）
- "妈妈"作为第三方，既是景甜的代称也是独立角色
- 不切换视角，不做全知叙述

## 六、修辞特征

| 修辞 | 使用方式 | 示例 |
|------|----------|------|
| 白描 | 零形容词叙事 | "坐在露台上，对着海，整个海是黑的" |
| 物件隐喻 | 用实物承载情感 | 指甲刀、旧照片、促排针、胶痕 |
| 对比 | 财富规模与情感空缺 | "一百万人的烟花 vs 凌晨三点的空" |
| 重复 | 关键句回旋 | "她不再爱我了吗"出现两次 |
| 留白 | 关键信息不交代 | "她没有说北京有什么。我也没问。" |

**核心规律**：零形容词、零抒情议论、零心理分析术语。情感只通过动作、对话和物件传递。

| 类型 | 示例 |

混用方式：不解释、不翻译、不加引号，直接嵌入中文句子。制造"这就是日常"的感觉。
